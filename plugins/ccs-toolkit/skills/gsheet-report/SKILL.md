# 구글 시트 자동화

**서식을 산출물마다 새로 쓰지 않는다.** 헬퍼 하나로 고정한다. 직접 `repeatCell` 을 흩뿌리면
시트마다 행 높이·색·정렬이 갈라진다.

## 0. 서비스 계정 발급 (한 번만)

1. Google Cloud Console → 프로젝트 생성
2. **Google Sheets API** 와 **Google Drive API** 사용 설정
3. 사용자 인증 정보 → 서비스 계정 만들기 → 키 추가(JSON) → 다운로드
4. **그 JSON 안의 이메일 주소**(`...@...iam.gserviceaccount.com`)를 대상 시트에 편집자로 공유

4번을 빼먹는 것이 첫 실패의 대부분이다. 서비스 계정은 사람 계정과 별개라, 공유하지 않으면
내가 소유한 시트도 못 연다.

```python
import gspread
from google.oauth2.service_account import Credentials

SCOPES = ["https://www.googleapis.com/auth/spreadsheets",
          "https://www.googleapis.com/auth/drive"]
creds = Credentials.from_service_account_file("key.json", scopes=SCOPES)
gc = gspread.authorize(creds)

sh = gc.open_by_key(SHEET_ID)        # 새로 만들 땐 gc.create("이름")
ws = sh.worksheet("데이터")
ws.update([HEADER] + ROWS, "A1")
```

> 키 파일은 **절대 커밋하지 않는다.** 환경변수에 JSON 문자열로 넣거나 시크릿 관리자를 쓴다.

## 1. 유형 판정 (먼저 이것부터)

| 유형 | 구조 규칙 | 탭 구성 |
|---|---|---|
| 대시보드·리포트 | 지표 세로(행) · **날짜 가로(열)** 고정 | 요약 1 + 지표별 1 |
| 장부·정산 | 실제 거래 **1건 1행**. 예정·합계 행을 섞지 않는다 | 요약(합계만) + 수입 + 지출 |
| 트래커·기획안 | 그룹 열만 병합·색, 나머지는 평평하게 | 1탭 원칙 |
| 폼 응답 처리 | 응답 시트는 **읽기 전용 취급**, 가공은 별도 탭 | 응답(원본) + 처리 |

- 요약 탭에 세부와 합계를 같이 두지 않는다. 합계는 **탭 참조 수식**으로 건다(`=SUM(지출!D:D)`).
- 만들기 전에 기존 시트 구조부터 확인하고 열 순서를 맞춘다. 사람은 열 위치로 기억한다.

## 2. 공통 포맷

| 항목 | 값 | 이유 |
|---|---|---|
| 행 높이 | 전 행 통일(28px 권장) | 들쭉날쭉하면 읽는 속도가 떨어진다 |
| 줄바꿈 | CLIP (셀 안 줄바꿈 금지) | 열 너비로 해결한다 |
| 헤더 | 색 채움 + 1행 고정 + 필터 | |
| 숫자 | `#,##0` 우측 정렬 | 금액은 정수로 다룬다 |
| 행 구분 | 줄무늬(밴딩) | 테두리 남발 금지 |
| 색 | 정해둔 한 벌만 | 시트마다 새 색을 고르지 않는다 |
| 긴 본문 | 첫 문장만 넣고 원문은 링크 열로 | 셀에 장문을 넣으면 표가 죽는다 |

## 3. 함정

| 증상 | 원인·해법 |
|---|---|
| `SpreadsheetNotFound` | 서비스 계정에 공유가 안 됐다(§0-4) |
| 숫자가 문자열로 들어감 | `value_input_option="USER_ENTERED"` 로 넣는다 |
| 날짜가 이상한 숫자로 | 시트는 날짜를 일련번호로 저장한다. 서식을 날짜로 지정 |
| 429 / 쿼터 초과 | 셀 단위 호출을 반복한 것. **범위 단위로 한 번에** 쓴다 |
| 대량 업데이트가 느림 | `batch_update` 로 묶는다 |
| 수식이 문자열로 보임 | 앞에 `'` 가 붙었거나 RAW 로 입력됐다 |
| 사람이 편집 중 덮어씀 | 자동 갱신 탭과 사람 편집 탭을 분리한다 |

## 4. 규칙

| 규칙 | 이유 |
|---|---|
| 원본 응답 시트는 건드리지 않는다 | 되돌릴 수 없다. 가공은 사본 탭에서 |
| 삭제 대신 상태 열 | 지운 행은 복구가 안 된다 |
| 자동 갱신 전 백업 탭 | 덮어쓰기 사고는 반드시 온다 |
| 실패는 알린다 | 조용히 빈 시트가 되는 게 최악이다 |
| 금액은 정수 연산 | 부동소수점으로 돈을 더하지 않는다 |
